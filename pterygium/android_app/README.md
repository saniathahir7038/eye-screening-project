# Pterygium Android screening prototype

This standalone Android app runs the accepted pterygium screening model entirely on the device. It is isolated from the SmartKC and DEDector applications.

## Included workflow

- Capture a new eye photograph with the installed camera app or select an existing image.
- Correct JPEG orientation and limit decode size to reduce memory pressure.
- Check minimum resolution, aspect ratio, brightness, contrast and sharpness before inference.
- Apply the Phase 2 top-left neutral mask and resize the image to 224 x 224.
- Run the selected float16 TensorFlow Lite model with float32 input and output.
- Apply the locked validation threshold `0.18100688606500626`.
- Show `No visible pterygium pattern` or a suspected-pterygium referral message.

The model score is not a calibrated probability. This is a research screening prototype and does not provide a diagnosis or severity grade.

## Build

Create `local.properties` with the local Android SDK path, select JDK 11, and run:

```powershell
$env:JAVA_HOME = "path/to/jdk11"
$env:GRADLE_USER_HOME = "path/to/gradle-home"
./gradlew.bat testDebugUnitTest assembleDebug
```

The debug APK is generated at `app/build/outputs/apk/debug/app-debug.apk`. Generated builds and APK files are ignored by Git.

## Model provenance

`app/src/main/assets/pterygium_model.tflite` is generated by `../export_tflite.py`. The selected model is a float16-weight conversion with float32 input and output. Its expected SHA-256 is:

```text
15ada3c60d498648cca005bde6182f7df90375cf30c46ac45d4929c54345511c
```

Conversion was checked against the accepted Keras model on all 61 validation images. It preserved 100% of threshold decisions with a maximum absolute score difference of 0.00415731. The locked test split was not reopened.

Physical-device camera, latency, thermal and memory testing remains required before any field study.
